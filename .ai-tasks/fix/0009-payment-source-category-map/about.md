# [0009] Потеря исключений в PaymentSourceService.MapCategories

## Контекст
`PaymentSourceService` в строках `:29,42,55` вызывает `async Task MapCategories` без `await`. Внутри метода на каждый `GetById` стоит `.Result`. Если категория не найдена, `KeyNotFoundException` остаётся в брошенном Task и теряется, а источник отдаётся с категорией, у которой заполнен только id. Плюс N+1: по запросу на каждую категорию.

## Постановка
- Убрать `MapCategories`: категорию источника заполнять в репозитории через JOIN (`PaymentSourceCategory`) одним запросом.
- Убрать ставшую ненужной зависимость `ICategoryService` из `PaymentSourceService`.

## Вне объёма
- Перевод `PaymentSourceRepository` на async (0015) — допустимо сделать попутно только для затронутых методов.
