# [0007] Неверные заголовки периодов на главной

- **Ветка:** `fix/0007-period-header-format`
- **Репозитории:** frontend
- **Создана:** 2026-10-20
- **Источник:** `.ai-docs/project/architecture-audit.md`, §4

## Контекст
`PaymentsTable.vue:379-384` (`formatPeriodHeader`) всегда разбирает ключ периода как `MMyyyy`. Backend для Недели, Года и Дня отдаёт ключи в другом формате, поэтому заголовки получаются неверными. Кроме того, в `:390` выражение `formData.groupingType !== '0'` сравнивает число со строкой и всегда истинно.

## Постановка
- Вынести форматирование заголовка периода в чистую функцию, которая учитывает тип группировки.
- Исправить сравнение типа группировки.
