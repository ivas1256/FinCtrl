# [0008] Удалённые платежи в списке платежей источника

- **Ветка:** `fix/0008-source-payments-deleted`
- **Репозитории:** backend
- **Создана:** 2026-10-20
- **Источник:** `.ai-docs/project/architecture-audit.md`, §2.4, §4

## Контекст
В `PaymentRepository.GetBySource` (`:275-283`) нет условия `p.IsDeleted = 0`, поэтому модалка платежей источника (`PaymentSources.vue:374`) показывает и удалённые платежи.

## Постановка
- Добавить фильтр `IsDeleted = 0` в `GetBySource`.

## Вне объёма
- Объединение SELECT'ов платежей (0015).

## Критерии приемки
- [ ] На dev-базе у источника с удалённым платежом этот платёж больше не показывается в модалке
- [ ] Проверка SQL описана в plan.md (юнит-тестами SQL не покрывается)
- [ ] Сборка затронутых частей проходит без ошибок, нет новых предупреждений в изменённых файлах
- [ ] Все тесты зелёные
