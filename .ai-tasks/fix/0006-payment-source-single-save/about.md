# [0006] Не работает одиночное сохранение источника

- **Ветка:** `fix/0006-payment-source-single-save`
- **Репозитории:** backend, frontend
- **Создана:** 2026-10-20
- **Источник:** `.ai-docs/project/architecture-audit.md`, §4

## Контекст
`PaymentSources.vue:394-404` (`saveSingleItem`) отправляет `PUT /api/PaymentSourcesApi/{id}` без `paymentSourceId` в теле. На backend есть только `[HttpPut]` без шаблона (`PaymentSourcesApiController.cs:46`), поэтому запрос получает 404/405. Массовое сохранение работает.

## Постановка
- Добавить маршрут `PUT api/PaymentSourcesApi/{paymentSourceId}`: id берётся из роута, тело — `[FromBody]`. Старый `PUT api/PaymentSourcesApi` оставить: гайд запрещает ломать существующие URL.
- На frontend передавать корректный запрос.

## Вне объёма
- Глобальная обработка 404 для несуществующего id (0017).
