# [0033] Карточка сравнения: топ-3 и таблица подкатегорий

- **Ветка:** `feature/0033-comparison-card-content`
- **Репозитории:** frontend
- **Создана:** 2026-10-23
- **Источник:** `.ai-docs/project/payments-table-month-comparison-requirements.md` (далее СР) §4.4–4.8; критерии СР 25–32, 37
- **Зависит от:** 0031 (карточка, плитки), 0032 (расчёт строк, топ-3, сортировки, полос)

## Контекст
После 0031 карточка открывается и показывает сводку, после 0032 есть модель строк. Эта задача выводит содержимое карточки: какие подкатегории дали рост и снижение.

## Постановка
- **Топ-3** (СР §4.4): две колонки `col-12 col-md-6` «Выросли сильнее всего» / «Снизились сильнее всего»; строка — имя слева, `{стрелка} {Δ₽} · {Δ%}` справа цветом Δ; пусто — «Роста нет» / «Снижения нет».
- **Переключатель сортировки** (СР §4.5): `btn-group btn-group-sm`, `role="group" aria-label="Сортировка"`, «По категориям» (по умолчанию) / «По изменению», активная `btn-primary`, `aria-pressed`; выбор сохраняется при смене охвата, пока открыта страница.
- **Таблица подкатегорий** (СР §4.5): колонки «Категория» / П / Т (с `title` «по {D}») / полоса / «Δ»; оформление как у тепловой карты (ДТ §2, §4, §5.1), без тепла; внуки раскрываются шевроном, по умолчанию развёрнуты; служебные строки («(без подкатегории)», «Без категории») — имя `--fc-text-secondary`; нули — «—»; суммы П/Т — `formatCurrency` без знака; Δ — как в `DeltaCell` (общая разметка).
- **Расходящаяся полоса** (СР §4.5): ось 1px `#6c757d` по центру, рост — вправо `#dc3545`, снижение — влево `#198754`, высота 10px, радиус 3px, минимум 2px при Δ₽ ≠ 0, `aria-hidden="true"`; масштаб — из 0032 (не меняется при сворачивании).
- **Сноска** (СР §4.6): охват «Итого» и есть «Без категории» — ««Без категории» не входит в итог трат — разберите эти платежи на странице «Операции».»
- **Пустые состояния** (СР §4.7): лист — вместо топ-3 и таблицы «У категории нет подкатегорий — сравнение только по категории целиком.»
- **Узкие экраны** (СР §4.8): < 768px — топ-3 в столбик, колонка полос скрыта (`d-none d-md-table-cell`), таблица в `overflow-x: auto`, у страницы горизонтальной прокрутки нет.

## Решения исполнителя (неблокирующие)
- Цвета полос — новыми токенами в `src/assets/main.css` (`--fc-bar-up: #dc3545`, `--fc-bar-down: #198754`, `--fc-axis: #6c757d`), а не литералами в компоненте (страж `styleguide.spec.js`). Для доходной семантики охвата полосы не инвертируются: направление полосы — знак Δ₽, цвет — по тону Δ (как у ячейки), чтобы цвет полосы и числа совпадали.
- Отображение знака/стрелки в топ-3 и таблице — та же вью-модель, что у `DeltaCell` (`deltaCellView`-подобная функция для строки карточки), чтобы три места выглядели одинаково.
- Подписи колонок П и Т в шапке таблицы — короткие названия периодов («Сентябрь», «Октябрь», «Неделя 19.10–25.10» → «19.10–25.10»), функцией в `periodHeader.js`.
- Свёрнутость внуков — локальное состояние карточки, при смене охвата сбрасывается в «развёрнуто».

## Вне объёма
- Переход из строки карточки к платежам подкатегории (СР О5), экспорт, графики.
- Запоминание сортировки между визитами.

## Критерии приемки
- [ ] Карточка «Продукты»: «Выросли сильнее всего» — «Рынок ▲ +50 ₽ · +2 %»; «Снизились сильнее всего» — «Супермаркеты ▼ −6 600 ₽ · −24 %» (СР 25)
- [ ] Карточка «Итого»: топ-3 по СР 26, в таблице есть «Без категории» и сноска о ней
- [ ] Карточка «Итого»: самая длинная полоса — «Супермаркеты» (вся половина колонки), «Кафе» ≈ 68 % половины вправо; при сворачивании «Продукты» длины не меняются (СР 27)
- [ ] «По изменению» / «По категориям» меняют порядок строк по СР 28
- [ ] Родитель с собственными платежами — строка «(без подкатегории)», сумма строк = плитке (СР 29)
- [ ] Карточка по листу («Спорт») — заголовок, подпись, плитки и текст «У категории нет подкатегорий…» (СР 30)
- [ ] Экран 375px: плитки и топ-3 в столбик, колонки полос нет, прокрутка только внутри таблиц (СР 31)
- [ ] Суммы и проценты — функциями `format.js`; `sharedFormat.spec.js` и `styleguide.spec.js` проходят (СР 32)
- [ ] Внуки развёрнуты по умолчанию, шеврон их сворачивает (СР 37)
- [ ] Сборка проходит без ошибок
- [ ] Все тесты зелёные, на новую логику написаны юнит-тесты
