## Риски и открытые вопросы
- Порядок детей в ответе API уже соответствует `OrderIndex` — опираться на порядок массива `children`, не пересортировывать.
- Охват «Итого»: строки отбираются по флагам корня, «ВСЕГО» на backend — по флагам категории платежа (`IsIncludeInTotalResults`); при смешанных флагах сумма строк ≠ плитке сверх «Без категории» (СР §5.1). Не компенсировать на фронтенде, правило «ВСЕГО» не дублировать.
