# [0031] Главная: открытие карточки сравнения по клику на Δ

- **Ветка:** `feature/0031-comparison-card-open`
- **Репозитории:** frontend
- **Создана:** 2026-10-23
- **Источник:** `.ai-docs/project/payments-table-month-comparison-requirements.md` (далее СР) §3, §4.1–4.3, §4.7; критерии СР 16–24
- **Зависит от:** 0028 (колонка Δ, `DeltaCell.vue`), 0029 (выделение и клавиатура ячеек)

## Контекст
Колонка «Δ к прошлому периоду» уже показывает изменение по каждой категории (0028), но разобрать его по подкатегориям нельзя. По СР клик по Δ-ячейке открывает под таблицей карточку «{Т} против {П}». Эта задача делает механику открытия и каркас карточки со сводкой. Содержимое (топ-3, таблица подкатегорий) — задачи 0032–0033.

## Постановка
- Δ-ячейки категорий и «Итого» кликабельны (СР §3.1): `tabindex="0"`, `role="button"`, Enter/Space = клик, `aria-expanded`, `aria-controls` → id карточки, `aria-label` по СР §2.4, `title` «Сравнить {Т} и {П} по подкатегориям», ховер и `:focus-visible` — ДТ §5.4. Ячейки с «—» не кликабельны (`cursor: default`, без фокуса и ховера).
- Под таблицей одновременно открыт либо блок платежей, либо карточка — в одном месте (СР §3.2): клик по Δ закрывает блок платежей и открывает карточку; клик по ячейке периода закрывает карточку; клик по Δ другой категории перестраивает карточку; повторный клик по той же Δ — закрывает; «Скрыть» и `Esc` внутри карточки — закрывают.
- Выбранная Δ-ячейка — стиль «Выбранная» ДТ §5.4; на всю таблицу выбрана одна ячейка (период **или** Δ).
- Фокус (СР §3.3): при открытии — на заголовок карточки (`h5 tabindex="-1"`); при закрытии через «Скрыть»/`Esc` — обратно на Δ-ячейку, если строка видна, иначе на заголовок «Расходы по категориям».
- Прокрутка (СР §3.4): `scrollIntoView({ block: 'nearest' })` по самой карточке, `behavior: 'smooth'`, при `prefers-reduced-motion: reduce` — без плавности.
- Перезагрузка таблицы (`submitForm`: «Отправить», быстрый период, теги) закрывает карточку (СР §3.5); сворачивание родителя выбранной категории — не закрывает.
- Каркас карточки (СР §4.1–4.3): `section.card.border-0.shadow-sm.mt-4` на всю ширину; заголовок «{Т} против {П}» (`formatComparisonTitle`) · точка цвета + имя охвата («Родитель / Подкатегория» для дочерней, «Все траты» без точки для «Итого»), справа «Скрыть»; подпись-период («Октябрь — по 21 число, сентябрь — целиком» / «Оба месяца целиком», для других группировок — по СР §2.1, при тегах «, с учётом выбранных тегов»); три плитки «Т / П / Разница».
- Новые подписи (подпись-период, подписи плиток) — функциями в `src/utils/periodHeader.js`, не в компоненте.

## Решения исполнителя (неблокирующие)
- Карточка — отдельный компонент `ComparisonCard.vue`; состояние «что выбрано» — в `PaymentsTable.vue` (`categoryId` охвата или признак «Итого»), рядом с выбором ячейки периода.
- Карточку можно открыть и для доходных строк и «Накоплений» (СР §2.5): плитки показывают величину S по семантике строки (`magnitude`), подписи плиток — названия периодов, без слова «потрачено»; цвет «Разницы» — как у Δ-ячейки строки (инверсия для доходов).
- Подписи плиток для групп, кроме месяца: Т — «{название Т}, по {дд.мм}» (если Т неполный), П — название П; названия — те же, что в заголовке карточки.
- Повторный выбор ячейки периода после сохранения платежа в модалке (`savePayment`) не меняется; карточка при этом закрывается вместе с перезагрузкой — это следствие правила СР §3.5.
- Пока содержимого нет (0032–0033), под плитками ничего не выводится.

## Вне объёма
- Топ-3, таблица подкатегорий, полосы, сортировка, сноска, состояние «нет подкатегорий» — 0032 (расчёт) и 0033 (UI).
- Переход из карточки к платежам подкатегории (СР О5).

## Критерии приемки
- [ ] Клик по ячейке периода открывает блок платежей, как раньше; карточки нет (СР 16)
- [ ] Клик по Δ «Продукты» открывает карточку «Октябрь против сентября · Продукты», ячейка выделена `#0a58ca`, блок платежей закрыт, карточка в зоне видимости, фокус на её заголовке (СР 17)
- [ ] Повторный клик по той же Δ закрывает карточку и снимает выделение (СР 18)
- [ ] Клик по Δ другой категории перестраивает карточку, выделение переносится (СР 19)
- [ ] Клик по ячейке периода при открытой карточке закрывает её и открывает платежи (СР 20)
- [ ] Enter/Space на Δ-ячейке работают как клик, `aria-expanded` меняется (СР 21)
- [ ] «Скрыть» и `Esc` закрывают карточку, фокус возвращается на Δ-ячейку (СР 22)
- [ ] Смена тегов/периода/«Отправить» закрывает карточку (СР 23)
- [ ] Плитки «Продукты»: «Октябрь, по 21.10» 24 650,00 ₽; «Сентябрь» 31 200,00 ₽; «Разница» «▼ −6 550 ₽ (−21 %)»; подпись «Октябрь — по 21 число, сентябрь — целиком» (СР 24)
- [ ] Δ «Итого» открывает карточку «… · Все траты» по узлу «ВСЕГО»
- [ ] Δ-ячейка с «—» не фокусируется и не реагирует на клик (СР 11)
- [ ] Сборка проходит без ошибок
- [ ] Все тесты зелёные, на новую логику написаны юнит-тесты
