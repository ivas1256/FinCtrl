# [0036] Классификация источников платежей через AiAssistant

- **Ветка:** `feature/0036-ai-payment-source-classification`
- **Репозитории:** backend `FinCtrl/` / frontend `FinCtrl.Frontend/`
- **Создана:** 2026-11-03

## Контекст
Сервис `FinCtrl.AiAssistant` (задача 0035) умеет классифицировать источники платежей через LLM (`POST /payment-sources/classify`), но backend и UI его не используют. Названия источников из банковского файла неудобны для анализа («IP IVANOV», «YANDEX*5814*EDA» …) — нужна человекочитаемая классификация, которая задаётся автоматически при импорте и правится вручную.

## Постановка
Блок 1 — поле классификации:
1. В таблице `PaymentSources` — поля `Classification` (текст) и `IsAiClassified` (классификацию задала LLM, а не человек).
2. Страница «Источники платежей» — редактируемая колонка «Классификация»; ручное изменение значения ставит `IsAiClassified = false`.
3. Главная, «Распределение по источникам» — группировка по классификации, под названием группы серым — список оригинальных имён источников.

Блок 2 — автоклассификация при импорте:
1. Кнопка «Загрузить файл» переезжает со страницы «Операции» в меню (`App.vue`, под списком ссылок).
2. После импорта новые источники отправляются в AiAssistant пачками (размер — `AiAssistant:BatchSize` в appsettings, по умолчанию 30), классификация сохраняется с `IsAiClassified = true`.
3. Кнопка открывает модалку: выбор файла и «Загрузить»; после загрузки — вкладки «Новые платежи» и «Новые источники платежей» с таблицами.
4. На время загрузки и ожидания LLM — лоадер.

## Вне объёма
- Повторная классификация старых источников (без классификации) — только новые из импорта.
- Использование классификации в других отчётах (дашборд, тепловая карта) и в фильтрах.
- CORS в AiAssistant — его вызывает backend, не браузер.

## Критерии приемки
- [ ] Миграция `0004` добавляет `Classification NVARCHAR(200) NULL` и `IsAiClassified BIT NOT NULL DEFAULT 0`, идемпотентна, накачена на dev-базу
- [ ] «Источники платежей»: колонка «Классификация» редактируется и сохраняется (одиночное и массовое сохранение); у LLM-классификации значок «ИИ»; после ручного изменения значения `IsAiClassified = 0`, сохранение без изменения классификации флаг не трогает
- [ ] Главная: «Распределение по источникам» группирует по классификации (источники без неё — по своему имени), под группой серым — оригинальные имена источников
- [ ] Кнопки загрузки на «Операциях» нет; в меню под ссылками — «Загрузить файл», открывает модалку с выбором файла и кнопкой «Загрузить»
- [ ] Во время загрузки — лоадер, кнопки заблокированы; после — вкладки «Новые платежи (N)» и «Новые источники платежей (N)» с таблицами, у новых источников видна классификация
- [ ] Новые источники классифицируются пачками по `AiAssistant:BatchSize` (настройка в appsettings), классификация сохраняется с `IsAiClassified = 1`
- [ ] AiAssistant недоступен/ошибка LLM — импорт не откатывается, в модалке предупреждение, источники остаются без классификации
- [ ] Сборка проходит без ошибок
- [ ] Все тесты зелёные, на новую логику написаны юнит-тесты
