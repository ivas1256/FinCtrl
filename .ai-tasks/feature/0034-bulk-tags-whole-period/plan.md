## Ручная проверка
Preview `backend` + `frontend`, страница «Операции»:
1. «Назначить теги…» → период с несколькими операциями (в т.ч. без категории), категории не выбирать, выбрать тег → «Применить»: окно закрылось, «Тегами помечено операций: N», где N = число операций периода; у операций без категории тег появился (`read_page` / фильтр по тегу).
2. Повтор с выбранной категорией — помечены только операции этой категории.
3. Без тегов — ошибка «Выберите хотя бы один тег»; без периода — «Укажите период».
4. `read_network_requests`: тело запроса содержит `categoryIds: []`, ответ 200; консоль и логи backend без ошибок.

## Риски и открытые вопросы
- Случайное применение ко всему периоду, если пользователь забыл выбрать категорию. Митигируется подсказкой под полем; окно подтверждения — вне объёма.
- Операции с `ExcludeFromStats` тоже получат теги — это соответствует «операциям в заданном периоде».
