# [0034] Массовое назначение тегов всем операциям периода

- **Ветка:** `feature/0034-bulk-tags-whole-period`
- **Репозитории:** backend `FinCtrl/` + frontend `FinCtrl.Frontend/`
- **Создана:** 2026-10-26

## Контекст
На странице «Операции» (`src/pages/payments/Payments.vue`) есть окно «Назначить теги операциям»
(кнопка «Назначить теги…»): период + категории + теги → `POST api/PaymentsApi/bulk-tags`
(`PaymentService.BulkAssignTags`). Сейчас категории обязательны на всех уровнях:
фронтенд показывает «Выберите хотя бы одну категорию», DTO `BulkAssignTagsRequest` имеет
`[MinLength(1)]` на `CategoryIds`, сервис бросает `ValidationException("Не выбраны категории")`.
Пометить тегом все операции периода (например, «Отпуск» на неделю поездки) нельзя — приходится
выбирать все категории вручную, и операции без категории при этом всё равно не попадают.

## Постановка
Если в окне «Назначить теги» не выбрана ни одна категория, теги назначаются **всем** операциям
заданного периода:
- пустой список категорий = фильтра по категории нет; в выборку попадают и операции без итоговой
  категории, и операции с `ExcludeFromStats` (фильтр по периоду — тот же, что сейчас, `GetByDateRange`);
- непустой список — поведение прежнее (итоговая категория из списка, без учёта потомков);
- назначение остаётся аддитивным (уже проставленные теги не стираются);
- период и теги по-прежнему обязательны.

UI: поле «Категории» становится необязательным — плейсхолдер «Все категории» и подсказка под полем
«Не выбрано — теги получат все операции периода». Сообщение об успехе — прежнее
(«Тегами помечено операций: N»).

## Вне объёма
- Учёт дочерних категорий при выборе родителя (сейчас «без учёта потомков» — не меняем).
- Окно подтверждения перед применением ко всем операциям периода.
- Снятие тегов массово, фильтры по источнику/счёту в окне.

## Критерии приемки
- [ ] `POST api/PaymentsApi/bulk-tags` с `categoryIds: []` (или без поля) → 200, теги добавлены всем платежам периода, включая без категории; `affectedCount` = число платежей периода
- [ ] С непустым `categoryIds` поведение не изменилось (существующие тесты зелёные)
- [ ] Пустой `tagIds` и перевёрнутый период по-прежнему → 400
- [ ] В окне «Назначить теги» без выбранных категорий кнопка «Применить» не показывает ошибку «Выберите хотя бы одну категорию», а назначает теги всем операциям периода; у поля «Категории» плейсхолдер «Все категории» и подсказка
- [ ] Doc-комментарии контроллера/DTO и `project-summary.md` (раздел про `bulk-tags`) описывают новое правило
- [ ] Сборка проходит без ошибок
- [ ] Все тесты зелёные, на новую логику написаны юнит-тесты
