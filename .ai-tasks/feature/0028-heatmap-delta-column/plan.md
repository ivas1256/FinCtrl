## Журнал решений
- 2026-10-23: задача заведена. Одна колонка вместо двух — по СР (переопределяет ДТ §4.1). Колонка показывается при наличии `comparison`, а не «при ≥ 2 периодах» (ДТ §4.1): П может лежать вне фильтра — решено исполнителем, правило СР §2.2 приоритетнее. В12: инверсия цвета для доходов и «Накоплений».
- 2026-10-23: вью-модель ячейки (`deltaCellView`: стрелка, тон, скрытый текст) — чистая функция в `periodComparison.js`, `DeltaCell.vue` только рендерит; для раздельного веса Δ₽ (600) и «(Δ%)» (400) в `format.js` добавлен `formatDeltaPercent`, `formatDelta` собирается из него.
- 2026-10-23: знак «Накоплений» (риск из 0027) проверен на dev-базе: месячные суммы положительные (сен +110 000, окт +25 000), `magnitude` с `−v` показывал падение как «рост». Исправлено на `+v`, как у дохода (одна строка, тесты 0027 поправлены). Годовые суммы «Накоплений» на dev-базе отрицательные — формула та же, процент от `|S_П|`.
- 2026-10-23: скрытый текст «нет данных в обоих периодах» (в СР — «месяцах»): сравнение работает для всех группировок.
- 2026-10-23: вторая строка подписи — общая для всех группировок: «…«новая» — в прошлом периоде сумм по категории не было» (без падежа П: формы для недели/квартала/года/дня нет); фраза «Нажмите на изменение…» не выводится — Δ-ячейки в этой задаче не кликабельны. Старая сноска «Без категории» не входит в «Итого» сохранена третьей строкой.
- 2026-10-23: ширина колонки (СР-О14): «Δ К ПРЕД. НЕДЕЛЕ» помещается в 176px без переполнения (`scrollWidth ≤ clientWidth`). На узком окне колонка, как и колонки периодов, ужимается до содержимого (`nowrap`, таблица `width: auto`) — поведение прежнее, `min-width` не добавлялся.
