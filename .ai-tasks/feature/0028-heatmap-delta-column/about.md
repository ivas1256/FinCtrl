# [0028] Главная: колонка изменения к прошлому периоду

- **Ветка:** `feature/0028-heatmap-delta-column`
- **Репозитории:** frontend
- **Создана:** 2026-10-23
- **Источник:** СР §2 (переопределяет ДТ §4.1, §5.1); ДТ §3.4, §5.7; решения В5, В12
- **Зависит от:** 0024 (токены), 0025 («Итого» из «ВСЕГО»), 0026 (API), 0027 (расчёт и форматтеры)

## Контекст
Пользователь хочет видеть, в каких категориях траты текущего периода выросли или упали к прошлому. Документ сравнения заменяет две колонки «Δ, ₽» / «Δ, %» из макета одной: «▲ +4 500 ₽ (+61 %)».

## Постановка
- Последняя колонка таблицы «Δ к {П}» (СР §2.3): ширина 176px, левый разделитель, `title` с полной формулировкой. Показывается, когда в ответе есть `comparison` и таблица не пустая.
- Ячейка (СР §2.4): стрелка + Δ₽ (600) + «(Δ%)», цвета: рост трат — `#b02a37` ▲, снижение — `#146c43` ▼, без изменений — серый •, «—» без данных. Для доходных строк и «Накоплений» цвет инвертирован (В12). Скрытый текст «рост»/«снижение»/… для скринридеров.
- Δ у родителя — по его суммам (включая потомков); Δ в «Итого» — по узлу «ВСЕГО».
- Подпись под таблицей (СР §2.8): «Δ — {Т} по {D} против всего {П}» + легенда цветов; при выбранных тегах — «с учётом выбранных тегов».

## Вне объёма
- Клик по Δ и карточка сравнения (СР §3–§4) — отдельная задача, пока не заведена; в этой задаче Δ-ячейки не кликабельны.
- Липкая первая колонка (В9).

## Критерии приемки
- [ ] Дефолтный фильтр: последняя колонка — «Δ к {прошлому месяцу}» с разделителем (СР критерий 1)
- [ ] Неделя/квартал/год/день — колонка есть, подписи по СР §2.1 (критерий 2)
- [ ] Быстрый период «Месяц»: колонка есть, П — весь прошлый месяц, хотя его колонки в таблице нет (критерии 3–4)
- [ ] Примеры СР §7: «▲ +4 500 ₽ (+61 %)» красным, «▼ −6 550 ₽ (−21 %)» зелёным, «(новая)», «(−100 %)», «—» серым (критерии 7–11)
- [ ] Доходная строка: рост — зелёный ▲, падение — красный ▼
- [ ] «Итого» показывает Δ узла «ВСЕГО» (критерий 13)
- [ ] Свёрнутый родитель показывает свою Δ (критерий 14)
- [ ] С тегами — суммы отфильтрованы, подпись дополнена (критерий 15)
- [ ] Клик по ячейке месяца по-прежнему открывает платежи (критерий 16)
- [ ] Сборка проходит без ошибок
- [ ] Все тесты зелёные, на новую логику написаны юнит-тесты
