# [0040] «Накопления» по накопительным счетам

- **Ветка:** `feature/0040-savings-by-accounts`
- **Репозитории:** backend `FinCtrl/`, frontend `FinCtrl.Frontend/`
- **Создана:** 2026-11-07

## Контекст
Строка «Накопления» (id 33) на главной собиралась по категории: пользователь вручную ставил «Накопления» переводам, а модалка подставляла её при переводе на накопительный счёт. Проценты на остаток шли отдельной категорией «Проценты на остаток» в «Доходы». Теперь у счетов есть признак `IsSavings`, и «Накопления» должны считаться по нему.

## Постановка
1. Строка «Накопления» = сумма всех операций по счетам с `IsSavings = true` (переводы, проценты, снятия — любые). Такие операции не попадают ни в «Переводы», ни в «Доходы», ни в траты, ни во «ВСЕГО»; дашборд их тратами не считает.
2. Старое правило по категории 33 остаётся без изменений (операции до 2026 отдельно не обрабатываем).
3. Миграция: у операций за 2026 год снять собственную категорию «Накопления»; у операций со счётом снять категорию «Проценты на остаток» (они на накопительных счетах и попадут в «Накопления» по счёту).
4. Модалка главной больше не подставляет «Накопления» при переводе на накопительный счёт.
5. (Уточнение 2026-11-07) Если итоговая категория операции на накопительном счёте (своя ?? источника) — потомок «Накоплений» (например, «Накопления → Проценты»), операция показывается в этой подкатегории; любая другая категория игнорируется — операция в «Накоплениях». Потомки «Накоплений» не входят во «ВСЕГО».

## Вне объёма
- Удаление категории «Проценты на остаток»: у неё остаются операции без счёта (≈87) и 3 источника — пользователь решит позже.
- Перенос старых (до 2026) операций с категорией «Накопления» на счета.

## Критерии приемки
- [x] Операция на накопительном счёте (перевод, доход, трата, с любой категорией) — в строке «Накопления», не в «Переводах»/своей категории и не во «ВСЕГО»
- [x] Операция на накопительном счёте с категорией-потомком «Накоплений» (своей или источника) — в этой подкатегории, не во «ВСЕГО»
- [x] Вторая сторона перевода на обычном счёте — в «Переводах»
- [x] Операция с категорией «Накопления» без накопительного счёта — по-прежнему в «Накоплениях»
- [x] Дашборд не считает тратами операции накопительных счетов
- [x] Миграция `0007`: у операций 2026 нет собственной категории «Накопления»; у операций со счётом нет категории «Проценты на остаток»; операции без счёта и сама категория не тронуты
- [x] В модалке главной отметка перевода / выбор второй стороны на накопительном счёте не меняет категорию
- [x] Тепловая карта главной: «Переводы», «Без категории», «Накопления» и их потомки не влияют на шкалу и не подсвечиваются
- [x] Сборка проходит без ошибок
- [x] Все тесты зелёные, на новую логику написаны юнит-тесты
