# [0029] Главная: ячейки сумм — «—» для пустых, цвета, ховер, клавиатура

- **Ветка:** `feature/0029-heatmap-cells-a11y`
- **Репозитории:** frontend
- **Создана:** 2026-10-23
- **Источник:** ДТ §3.3, §5.2, §5.4, §8; решение В4, Р10
- **Зависит от:** 0024 (токены)

## Контекст
Нулевые ячейки показывают «0,00 ₽» цветом с контрастом 2.1:1 и по клику открывают пустой список. Текст расходов красный с недостаточным контрастом на тепле, ховер затемняет текст. Ячейки недоступны с клавиатуры.

## Постановка
- Ноль/нет данных: «—» цветом `#6c757d`, `aria-label="нет трат"`, без ховера, фокуса и клика, без `title`.
- Расходы — нейтральный `#212529` (класс `hm-hi` для текста убрать); поступления — `#146c43`.
- Ховер: `outline: 1px solid #6c757d; outline-offset: -1px`, фон не меняется (вместо `filter: brightness`).
- Клавиатура: `tabindex="0"`, `role="button"`, Enter/Space = клик, `aria-label="{категория}, {период}: {сумма}"`, `:focus-visible` — `outline 2px #0a58ca`.
- Выбранная ячейка: обводка `#0a58ca`, `font-weight: 600`, `aria-pressed="true"`; выбранная + фокус — дополнительная внутренняя тень.

## Вне объёма
- Формат сумм в ячейках — остаётся с копейками (В2).
- Колонка Δ — задача 0028.

## Критерии приемки
- [ ] Пустая ячейка показывает «—», не реагирует на клик и не получает фокус
- [ ] Текст расходов `#212529`, поступлений — `#146c43`
- [ ] Ховер рисует рамку, текст не темнеет
- [ ] Tab проходит по ненулевым ячейкам, Enter/Space открывают платежи, обводка фокуса видна
- [ ] Выбранная ячейка — обводка `#0a58ca`, жирная сумма, `aria-pressed`
- [ ] Сборка проходит без ошибок
- [ ] Все тесты зелёные, на новую логику написаны юнит-тесты
