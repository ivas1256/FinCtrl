# [0030] Главная: раскрытие категорий шевроном по имени

- **Ветка:** `feature/0030-heatmap-expand-chevron`
- **Репозитории:** frontend
- **Создана:** 2026-10-23
- **Источник:** ДТ §5.3, §8, Р12
- **Зависит от:** 0024 (токены, `gap` вместо `me-1`)

## Контекст
Сейчас родительская категория раскрывается маленькой кнопкой «+»/«−» 22px. По макету A кликабельно всё имя, а состояние показывает шеврон.

## Постановка
- Имя родительской категории — `<button type="button">` со сброшенными стилями (`display:flex; gap 8px; width:100%; min-height:22px; cursor:pointer`), `aria-expanded`.
- Внутри — шеврон `▸`/`▾` (12px, `#6c757d`, `aria-hidden="true"`) в колонке 22px; у листьев — пустой плейсхолдер той же ширины, чтобы имена одного уровня стояли на одной линии.
- `:focus-visible` — по ДТ §5.4. По умолчанию всё раскрыто.

## Вне объёма
- Раскрытие в карточке сравнения.

## Критерии приемки
- [ ] Клик по имени родителя сворачивает/раскрывает ветку, шеврон меняется ▸/▾
- [ ] `aria-expanded` отражает состояние; кнопка доступна с клавиатуры, фокус виден
- [ ] Имена одного уровня выровнены у родителей и листьев
- [ ] По умолчанию все ветки раскрыты
- [ ] Сборка проходит без ошибок
- [ ] Все тесты зелёные, на новую логику написаны юнит-тесты
