# [0038] Номер счёта у счетов и сопоставление при импорте по номеру

- **Ветка:** `feature/0038-account-number`
- **Репозитории:** backend `FinCtrl/`, frontend `FinCtrl.Frontend/`
- **Создана:** 2026-11-06

## Контекст
Счёт (`Account`) при импорте ищется/создаётся по названию из колонки C xlsx (`ExcelAccountName`).
Названия у разных счетов могут совпадать; надёжный ключ — номер счёта. Он есть в выгрузке банка —
колонка D (раньше разбиралась как «номер операции» `ExcelPayment.InvoiceNumber` и нигде не использовалась).

## Постановка
- У счёта появляется поле «Номер счёта» (БД, API, страница «Счета» — просмотр, создание, правка).
- Импорт xlsx читает номер счёта из колонки D так же, как название из колонки C.
- Счёт при импорте сопоставляется по номеру: найден по номеру — берём его; не найден — счёт с тем же
  названием без номера (созданный до этой задачи) получает номер; иначе создаётся новый счёт с названием и номером.
  Строка без номера — прежнее поведение по названию.
- Номер уникален (если задан); название больше не уникально.

## Вне объёма
- CSV-импорт номер счёта не читает (решение пользователя).
- Номер счёта в данных платежа (`SelectPayment`/`PaymentDto`) не отдаётся.
