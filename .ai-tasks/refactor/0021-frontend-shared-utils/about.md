## Контекст
По frontend разбросано 6 копий `formatCurrency` и 6 копий `formatDate`, форматы у них разные. В `PaymentsTable.vue:364-368` дата форматируется через `toISOString()`: это UTC, и дата может сдвинуться на день. Адрес API жёстко задан в `config.js`, который лежит вне `src/`.

## Постановка
- Создать `src/utils/format.js` (деньги, дата, дата для input без UTC-сдвига) с тестами; заменить копии.
- Адрес API — `import.meta.env.VITE_API_BASE_URL` с дефолтом `http://localhost:5000`, `.env.example`; обновить CLAUDE.md. _(Уточнено при выполнении: `.env.example` не добавлен — хук pre-pr-check блокирует `.env.*`; переменная описана в `CLAUDE.md` и `src/config.js`, см. журнал решений в `plan.md`.)_
- Исправить сдвиг даты на день раньше в модалке правки платежа на главной (отложенный баг, UTC-сдвиг `toISOString()`).
- Опционально (согласовать): тонкий модуль загрузки справочников (`getTree`, теги, счета), которые дублируются в 3–5 местах.
