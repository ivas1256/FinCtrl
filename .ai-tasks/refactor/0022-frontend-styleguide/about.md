## Контекст
Расхождения со стайлгайдом:
- Options API в `PaymentCategoryRow.vue`, `PaymentList.vue`, `PaymentSourcesList.vue`;
- около 30 вызовов `alert()` вместо error-состояния;
- в `PaymentsTable` нет спиннера, модалки без `modal-lg`;
- шаблонный `assets/base.css` с тёмной темой через `prefers-color-scheme`.

## Постановка
- Перевести 3 компонента на `<script setup>`.
- `alert()` → error-состояние по стайлгайду.
- Спиннер загрузки в `PaymentsTable`, `modal-lg` в модалках правки (главная, Операции).
- Решить судьбу `assets/base.css` (удалить/заменить минимальными стилями) — согласовать с пользователем, т.к. меняет внешний вид.
