# [0022] Привести frontend к стайлгайду

- **Ветка:** `refactor/0022-frontend-styleguide`
- **Репозитории:** frontend
- **Создана:** 2026-10-20
- **Источник:** `.ai-docs/project/architecture-audit.md`, §3

## Контекст
Расхождения со стайлгайдом (сверено с кодом после задач 0017–0021):
- Options API в `PaymentCategoryRow.vue`, `PaymentList.vue`, `PaymentSourcesList.vue`;
- 31 вызов `alert()` в 7 файлах вместо error-состояния (ошибки загрузки/сохранения, валидация форм, сообщения об успехе массовых операций);
- в `PaymentsTable` нет спиннера загрузки, модалки правки (главная, «Операции» — массовое назначение тегов) без `modal-lg`;
- шаблонный `assets/base.css` (из `create-vue`): тёмная тема через `prefers-color-scheme` красит только фон/текст `body`, а карточки Bootstrap остаются белыми — в тёмной теме ОС заголовок страницы на чёрном фоне и текст карточек почти не видны; `transition` цвета/фона у `body`; цвет текста `#2c3e50` вместо Bootstrap `#212529`, шрифт Inter.

Отложено в эту задачу из 0019–0021:
- горизонтальная прокрутка в выпадающем фильтре источников «Операций» при длинных названиях;
- в `PaymentList.vue` `payment.paymentSource.description` без `?.` (падение при платеже без источника);
- в разделе «Frontend» `project-summary.md` устаревший список роутов (нет `/tags`).

## Постановка
- Перевести 3 компонента на `<script setup>` без изменения поведения.
- `alert()` → error/success-состояние: общий компонент `AlertMessage.vue` (Bootstrap `alert`, закрывается крестиком) + composable `useAlerts()`; ошибки в модалках — внутри модалки, ошибка создания тега — под полем тегов. Описать паттерн в стайлгайде.
- Спиннер загрузки в `PaymentsTable` (вместо таблицы, по стайлгайду 4.8) и пустое состояние «Нет данных»; `modal-lg` в модалках правки (главная, «Операции»).
- `assets/base.css` удалить; `main.css` — минимальные глобальные стили поверх Bootstrap. Тема только светлая (Bootstrap по умолчанию), правило тёмной темы в `PaymentCategoryRow.vue` убрать.
- Исправить отложенные мелочи: перенос длинных названий в фильтре источников, `?.` в `PaymentList.vue`, список роутов в `project-summary.md`.
- Статические тесты-«сторожа» стайлгайда (нет Options API, `alert(`, `prefers-color-scheme`, `base.css`; модалки правки — `modal-lg`) и тесты ключевого поведения изменённых компонентов.

## Вне объёма
- Редизайн, поддержка тёмной темы (`data-bs-theme="dark"`).
- Замена `confirm()` на модалку подтверждения (стайлгайд её не требует, критерий — только `alert()`).
- Юнит-тесты на остальной текущий функционал — задача 0023.

## Критерии приемки
- [ ] Нет Options API в `src/`
- [ ] Нет `alert()` в `src/`; ошибки и сообщения об успехе показываются через `AlertMessage`
- [ ] Спиннер и `modal-lg` по стайлгайду
- [ ] Решение по `base.css` принято и реализовано: файл удалён, в тёмной теме ОС приложение выглядит как в светлой (всё читаемо)
- [ ] Фильтр источников «Операций» не прокручивается по горизонтали при длинных названиях
- [ ] Список платежей на главной не падает на платеже без источника
- [ ] Ручная проверка всех страниц (светлая/тёмная тема ОС, мобильная ширина), нет ошибок в консоли
- [ ] `styleguide.md`, `project-summary.md` актуализированы
- [ ] Сборка затронутых частей проходит без ошибок, нет новых предупреждений в изменённых файлах
- [ ] Все тесты зелёные
