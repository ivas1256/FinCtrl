- 2026-10-20: судьба `base.css` (в постановке — «согласовать с пользователем») решена без вопроса по поручению: файл удалён целиком. Причины: это шаблон `create-vue`, его тёмная тема ломает читаемость (карточки Bootstrap остаются белыми), `transition` у `body` даёт мигание в dev, переменные `--color-*`/`--vt-*` нигде не используются. Тема — только светлая (Bootstrap 5.3 по умолчанию); поддержка тёмной темы — отдельная задача при необходимости. Шрифт/цвет/межстрочный — из Bootstrap; оставлен только базовый размер текста 15px (`--bs-body-font-size`), чтобы не менять плотность таблиц.
- 2026-10-20: вместе с `base.css` убрано правило `prefers-color-scheme: dark` в `PaymentCategoryRow.vue` (светлый текст `#ffcdd2` на светло-розовом фоне в светлой теме стал бы нечитаемым).
- 2026-10-20: формат сообщений вместо `alert()` — общий `AlertMessage.vue` (Bootstrap `alert-dismissible`, закрытие крестиком, без автоскрытия — детерминированно и ничего не теряется) + `useAlerts()` (`error`/`success`, взаимоисключающие). Ошибки загрузки/сохранения на странице — над содержимым карточки; ошибки в модалках (правка платежа, категории, массовые теги, платежи источника) — внутри модалки, т.к. страница под модалкой не видна; ошибка создания тега в `TagMultiSelect` — мелким текстом под полем (компонент стоит в строках таблицы). Сообщения об успехе массовых сохранений тоже переведены в `AlertMessage` (`success`). Загрузка данных сбрасывает сообщения.
- 2026-10-20: `confirm()` (удаление счёта/тега, смена страницы с несохранёнными изменениями) оставлены — критерий задачи только про `alert()`, стайлгайд модалку подтверждения не требует (см. «Вне объёма»).
- 2026-10-20: модалка подтверждения удаления категории оставлена стандартного размера — `modal-lg` по стайлгайду для модалок с формами; исключение для подтверждений описано в стайлгайде (4.11).
