## Журнал решений
- 2026-10-20: задача заведена по итогам аудита архитектуры (`.ai-docs/project/architecture-audit.md`).
- 2026-10-20: отступление от п.1.2 регламента — ветка создана от `refactor/0019-frontend-template-cleanup` (PR #22, стек #9→…→#22 не смёржен), а не от `main`; PR открывается в базу `refactor/0019-frontend-template-cleanup`, мёржить после #22. Хук pre-pr-check смотрит дифф `main...HEAD`, поэтому собирает и backend предыдущих задач — ожидаемо.
- 2026-10-20: отдельный `import 'bootstrap'` (JS) в `main.js` не добавлен: из JS используется только `Modal`, а `import { Modal } from 'bootstrap'` грузит ESM-сборку `bootstrap.esm.js`, которая при загрузке регистрирует data-API (в т.ч. `data-bs-dismiss="modal"`); `@popperjs/core` ставится зависимостью пакета `bootstrap`. Других data-API (dropdown/collapse и т.п.) в коде нет.
- 2026-10-20: CSS Bootstrap импортируется в `main.js` первым, до `assets/main.css` и `vue-multiselect` — сохраняет прежний порядок каскада (CDN-`<link>` стоял в `<head>` раньше стилей Vite).
- 2026-10-20: вместо `new bootstrap.Modal(...)` при каждом открытии и `getInstance` при закрытии — `Modal.getOrCreateInstance(el)` (есть с 5.1): один экземпляр на элемент, без накопления экземпляров при повторных открытиях; `hide()` не падает, если модалка не была создана.
- 2026-10-20: критерий «модалки Счета, Теги» — на этих страницах модалок нет (правка инлайн); проверены только загрузка и внешний вид страниц.
- 2026-10-20: «Визуальных регрессий нет» трактуется как «раскладка не изменилась, нет сломанных элементов». Поэлементное сравнение: геометрия всех 7 страниц совпала (0 отличий), различаются только штатные токены 5.3 (скругления, цвет рамок, `text-muted`, цвет текста внутри `.card`/`.table` = `--bs-body-color` `#212529` вместо `#2c3e50` из `base.css`). Это и есть переход на 5.3, которого требует стайлгайд; переопределять токены под 5.0 не стали — судьба `base.css` решается в 0022.
- 2026-10-20: первый снимок «после» показал у контейнеров цвет `rgb(0,0,0)` — артефакт замера: в dev CSS инжектится скриптом, `base.css` задаёт `transition` цвета у `body`, а в скрытой панели переход не доигрывается. Повторный снимок с `transition: none` и проверка в видимой вкладке — `#2c3e50`, как раньше. Записано граблей в `project-summary.md`.
- 2026-10-20: массовое назначение тегов в ручной проверке не отправлялось (после успеха — `alert()`, блокирующий панель браузера); путь `hide()` после сохранения проверен на модалке главной (PUT 204, модалка закрылась). Удаление тестового тега — через SQL (в UI — `confirm()`).
