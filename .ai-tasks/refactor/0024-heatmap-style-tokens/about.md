# [0024] Главная: цветовые токены, мелкие правки стиля и панель фильтров

- **Ветка:** `refactor/0024-heatmap-style-tokens`
- **Репозитории:** frontend
- **Создана:** 2026-10-23
- **Источник:** `.ai-docs/project/payments-table-design-requirements.md` (далее ДТ) §2–§4, §5.1, §5.5, §6, §8; решения В7, В10

## Контекст
Цвета главной заданы литералами в scoped-стилях, часть из них не проходит по контрасту (текст `th`, «Итого»). Легенда-градиент не совпадает с реальной тепловой шкалой. Мультиселект тегов по высоте выбивается из ряда `sm`-контролов. Задача готовит общие токены, на которые опираются задачи 0028–0030.

## Постановка
- Завести CSS-переменные `--fc-*` из ДТ §3 в `src/assets/main.css` (`:root`, только светлая тема); в `PaymentsTable.vue` и `PaymentCategoryRow.vue` заменить литералы цветов на `var(--fc-*)`.
- Шапка таблицы: текст `th` — `#5c636a`, у `th` колонок — `scope="col"`.
- «Итого»: текст `#0a58ca` (линия сверху остаётся `2px #0d6efd`).
- Легенда-градиент в шапке карточки: `rgba(200,76,78,0.04)` → `rgba(200,76,78,0.36)` (как шкала `heatmap.js`).
- Карточка таблицы: `mt-4` → `mb-4` (СГ §5).
- «Без категории»: имя цветом `--fc-text-secondary`, вес 400.
- Промежутки в ячейке категории — только `gap` (убрать `me-1` у кнопки раскрытия и плейсхолдера).
- Панель фильтров (В10): `TagMultiSelect` подогнан под `sm` (высота 31px, рамка `#dee2e6`, радиус 4px, шрифт 14px); «Отправить» прижата вправо; у быстрых периодов — `aria-pressed`; ручная смена дат сбрасывает активный быстрый период.
- Документ `.ai-docs/project/payments-table-heatmap.md`: обновить устаревшее (ДТ §9, последний абзац) и добавить в §11 исключение про зелёный для снижения трат (решение В5).

## Вне объёма
- Значения/цвета чисел в ячейках, «—» для нулей, ховер/фокус — задача 0029.
- Шеврон раскрытия — задача 0030.
- Колонка Δ — задача 0028.
- Липкая первая колонка, адаптивное меню (В9).
