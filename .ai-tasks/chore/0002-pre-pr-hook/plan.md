## Риски и открытые вопросы
- Ложные срабатывания проверок диффа (например, `Password=` в документации) — проверки ограничены кодовыми файлами.
- Сборка frontend+backend может занять минуты — таймаут хука 600 с, кэш по SHA.

## Журнал решений
- 2026-10-19: выбран `PreToolUse`-хук Claude Code, а не git `pre-push`: ловит и `gh pr create`, отдаёт отчёт агенту, хранится в репозитории.
- 2026-10-19: команда распознаётся только в позиции команды (начало строки или после `;`, `&`, `|`, `(`) — первая версия ловила `git push` внутри строк-данных. Упоминание после `&&` внутри кавычек всё ещё срабатывает — принятая эвристика (лучше лишний блок, чем пропуск).
- 2026-10-19: «нет новых предупреждений» реализовано как «нет предупреждений в файлах диффа» — сравнение со сборкой `main` слишком дорогое.
