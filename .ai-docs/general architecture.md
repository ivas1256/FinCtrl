FinCtrl - это приложение для учета финансов. НА момент 07.09.2026 оно сырое. Основная идея что в приложение загружается excel файл выгрузка операций из банка
далее на основании источника платежа определяется категория (категории пользователь задает сам в приложении). Действует система когда и у платежа есть возможность задать категорию
и у источника платежа задается категория. Категория источника платежа задает категорию для всех платежей с этим источником. Категория платежа задает категорию только для этого платежа 
и имеет приоритет над категорией источника.
